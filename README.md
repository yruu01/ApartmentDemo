# Apartments

A responsive apartment rental website demo built to showcase a clean and simple property browsing experience.

🌐 **Live Demo:** [Apartments](https://apartmentd.netlify.app/)

## Features

- Responsive layout
- Apartment listings
- Studio, 1 Bedroom, 2 Bedroom, and Penthouse pages
- Apartment pricing and details
- Amenities section
- About page
- Contact page
- Mobile-friendly navigation

## Built With

- HTML
- CSS
- JavaScript

## Purpose

This project was created as a portfolio/demo project to demonstrate my frontend web development skills.

> **Demo Project — Not an official business website.**
